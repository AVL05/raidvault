# Architecture Decision Records

RaidVault uses ADRs for decisions that materially constrain future implementation.

## Status values

- Proposed
- Accepted
- Superseded
- Rejected

## Format

Each ADR should contain:

1. Status
2. Context
3. Decision
4. Consequences

Accepted ADRs are architectural constraints. Agents must not silently contradict them.
