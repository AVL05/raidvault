# Changelog

## [0.1.0] - Unreleased

### Added

- Local-first domain, validated game-data adapters and provider abstraction.
- Stash browsing, search/filtering, item details and snapshot status.
- Deterministic classification, quantities, structured reasons and quest/project
  planning with missing-item and raid-priority facts.
- Minimal local Bridge endpoints and Gaming Mode safety foundation.
- Optional local WebGPU lifecycle contracts and capability reporting.
- ARC AI verified-context controller, bounded chat and read-only tool architecture.
- PWA manifest/icons, generated allowlisted offline shell and waiting updates.
- Versioned normalized snapshot storage, validated stale/local restore and
  recomputation of deterministic facts.
- Privacy / Storage reporting and independently confirmed snapshot/shell clearing.
- Keyboard/focus/status accessibility and deterministic performance budgets.
- Release-preparation documentation and pinned CI validation configuration.

### Security / Safety

- No game memory access, anti-cheat interference, packet interception or gameplay
  automation; no game-file modification, injection or rendering hooks.
- Rules Engine facts remain authoritative; AI is optional, read-only and cannot
  override deterministic safety rules.
- UNKNOWN game-running status fails safely and blocks heavy AI work.
- Snapshot persistence excludes raw provider DTOs, credentials and derived AI/rules
  authority. Shell cleanup excludes unrelated caches and model artifacts.
- No telemetry, analytics, remote sensitive logging or cloud AI fallback.

### Known limitations

- Synthetic/demo data only; no live provider/account integration or complete
  current game catalog.
- Workshop planning is unavailable in the current UI.
- No approved production model/runtime or configured model artifact store.
- No approved game executable identity or browser-to-Bridge integration;
  production Gaming Mode remains UNKNOWN.
- Public deployment/PWA verification and hosted CI results are pending.
- Browser APIs/storage can be unsupported, restricted or evicted.
- License and deployment-host decisions remain unresolved. This is preparation
  for Public Preview (Pre-alpha), not a published or production-ready release.
